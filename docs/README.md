# GreenTech System
## 1. Gioi thieu

GreenTech System la he thong quan ly ha tang

cho startup cong nghe va cac tram cam bien IoT.

He thong ho tro:

- Quan ly cau truc thu muc du an.

- Loc log va tong hop su co.

- Quan ly danh muc linh kien phan cung.

- Doi soat thong tin cac tram IoT.
## 2. Cau truc du an
```text
greentech-system/

├── docs/

├── scripts/

├── data/

├── backup/

└── .env
```
## 3. Huong dan chay script
Mo PowerShell tai thu muc goc du an:
```powershell
cmd.exe /c ".\scripts\auto_report.bat"
```
Xem bao cao:
```powershell
Get-Content .\backup\bao-cao-su-co.txt
```
